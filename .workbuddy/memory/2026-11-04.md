### 踩到的坑（都已修，README 也记了）

1. **`%20` 不能用 `%` 格式化**：`"…var%20_%s=" % sym` → `ValueError: unsupported format character '_'`。改字符串相加。
2. **夜盘判定用字符串比较会翻车**：时间字段可能是 `9:11:34`，`"9:11" >= "20:55"` 为 True → 日盘被标成夜盘。改按分钟数比较。
3. **`main_pick` 结构必须是 `{main:{…}, ranking:[…]}`**：我先写成扁平对象，页面上「主力合约」恒显示 `--（--）· 成交 0 手`，但 ranking 正常 → 只错一半、极易漏看。
4. **滚动 σ 恒为 None**：先把 dates 截到 121 根再滚 60 日，`len(dates)-60` 只剩 61 个起点 → 样本不足。改用 260 根窗口滚。
5. **601028 玉龙股份日K停在 2025-03-26**（停牌），标的池只有 15 只 → 换成 000506 中润资源（斐济金矿），凑齐 16 只。
6. **竞价时点各月合约返回持仓 0** → 主力变成空。改成：全表为空→近 6 个月重试；仍为空→沿用上次识别结果（`_LAST_MAIN`）。

### 新增端点

- `/api/reports`：东财 `reportapi.eastmoney.com/report/list`。
  `{page,size}` 全市场分页、`{code,size}` 单票。字段名必须照抄东财原始名
  （`emRatingName` / `infoCode` / `predictThisYearEps`），前端 `renderReportList` 直接用。
  **`beginTime` 是必填**，缺了 400；带 `cb` 回 JSONP 需剥壳；`pageSize` 上限 500。
  全市场模式下我给标题加了 `【股票名】` 前缀 —— 前端只渲染「标题+机构」，东财标题多为
  「2026年三季报点评：…」，不加前缀整屏分不清是哪只票（个股模式不加，避免重复）。
- `/api/ind15`：新建 `ind15.py`。三层口径全部引自官方：6 大新兴支柱（集成电路/航空航天/
  生物医药/低空经济/新型储能/智能机器人）+ 6 大未来产业（量子/生物制造/氢能核聚变/
  脑机接口/具身智能/6G）+ 4 个基础盘（工业母机/基础软件/先进材料/算力）。
  16 个产业、89 只标的，**名称与 secid 运行时从快照取**（银泰黄金已改名山金国际、南都电源已 ST，
  写死就会显示旧名）。ST 自动剔除。
- `/api/screen`：东财 `push2 clist`。只做排序+翻页+计数（`diff/total/fetched`），
  过滤全在前端。实测 total 5927、2 页 200 只 0.4s。
- `/api/fund`：东财 `RPT_LICO_FN_CPD`。最新报告期 + 2025/2024/2023 年报，
  5766 只、3.2s、1.3MB，缓存 6 小时。`cf_ratio = 每股经营现金流 / 每股收益`（近似）。
  同报告期同票有重复行（count 11534≈2×5766），必须按 `UPDATE_DATE` 去重。

   并把翻页终止条件从 `len(chunk)<100` 改成 `not chunk`。本次已重建快照：5464 只 / 3.1s / 1.53MB。
2. **`api_watchlist_get` 只回 `{code}`** → 研究中心那行「自选股快捷诊断」渲染出 `undefined`。
