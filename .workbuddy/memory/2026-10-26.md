### 算法口径（与文档 28 章一致）
- 成熟度 = 结构25 + 突破15 + 量能20 + 动量15 + 位置25（合计 100）
- 综合分 = 成熟度×0.6 + 缠论×0.4（对齐前端 `CHAN_W` / `RS_COMPOSITE_W`，弃用原站 45/35/20）
- 缠论：包含处理→分型→笔(≥4根)→中枢(3笔重叠)→背驰(MACD面积<75%)→三类买卖点；**分型索引必须换回原始 K 下标**，否则切 hist 错位
- 惩罚要「相干性修正」：均线仍多头时中枢下移只减 6 而非 18，否则强势股被打到 0 分
- 走势类型按**现价 vs 最后一个近端中枢（70 根内）的上下沿**判，不用中枢序列（序列会滞后）
- 止损 = min(1.6×ATR%, 结构失效位距离, 8%)，下限 2.5%；原「取2×ATR更保守者」实测全部顶到 −8%
- 破位/走弱**只在命中六池的候选里判**；对全市场判「收盘<MA60」会剔掉 4000 只
- 平台池振幅用**不含当日**的前 20 根，否则当日突破撑破 8%，该池恒为 0

### 踩坑
- **Windows 上两个进程可同时 bind 8092**（SO_REUSEADDR），旧进程继续吃请求 → 表现为「改了代码不生效」。必须用 `netstat -ano | grep 127.0.0.1:8092 | grep LISTENING` 查 PID 并全杀
- 后台 python 需 `-u`，否则 print 全缓冲看不到启动日志
- `/tmp` 是 git-bash 虚拟路径，Windows python 用绝对 `/tmp/x.json` 会 FileNotFound；必须先 `cd /tmp` 用相对路径
- `checkup` 批量 slim 返回缺少 `ok` 键 → api 层 `if r.get("ok")` 全过滤掉，items 为空
