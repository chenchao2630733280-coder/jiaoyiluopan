## 0. 一句话总纲

这套系统的核心只有一句话（原站 `rightside.concept.desc` 原文）：

> 不猜底、不猜顶，等市场用价格证明趋势已经改变，再顺势动手。代价是放弃最低点附近的一段利润，换来确定性。

工程上它被拆成 **「全市场扫描 → 位置分级 → 多池命中 → 多维度打分 → 硬性否决 → 交易计划生成」** 六段流水线，任何一段不通过都不出买点。全站 26 个功能模块本质是同一套引擎的不同切片。

## 3. 核心方法论（原站原文，直接决定所有阈值）

### 3.1 三位置理论 [接口] `rightside.concept.positions`

| 位置 | 名称 | 定义（原文） | 风险 | 结论 |
|---|---|---|---|---|
| `pos1` | 位置 1 · 追高 | 在上冲箭头的末端买入。运气好有一点获利空间，运气差就买在向上箭头的末端与向下箭头的临界位置 | 高 | **回避** |
| `pos2` | 位置 2 · 猜支撑 | 在冲高回落中猜股价止跌回升的位置，选择关键支撑位介入。有技术基础，但本质仍是在预测 | 中 | **谨慎** |
| `pos3` | 位置 3 · 右侧交易 | 不预测股价，等市场明确转折、出现确切介入信号后再操作 —— 股价阶段弱势已经衰竭、强势开始的初段 | 低 | **推荐** |

### 3.2 四重确认 [接口] `concept.confirmations`（实际列出 5 项，第 5 项被定位为"否决项"）

| 确认维度 | 权重定位 | 具体标准（原文） |
|---|---|---|
| 价格结构 | 前提 · **权重最高** | 更高的高点 + 更高的低点；突破前期平台颈线 / 下降趋势线 / N 日新高；均线多头排列（股价在所有重要均线上方 = 各周期持仓者都浮盈，抛压最轻） |
| 量能 | **真假突破的分水岭** | 突破日放量（**≥20 日均量 1.5 倍**）；回踩时缩量不破；价涨量缩警惕假突破 |
| 均线结构 | 趋势方向 | 短期均线依次上穿长期均线形成多头排列；股价站上 60/120 日线且均线走平转向上 |
| 市场环境 | **决定策略胜率基线** | 个股是船、大盘是水：指数在 60 日线上方且向上是前提；主线板块的普通突破胜率 > 冷门板块的完美突破 |
| 动量指标 | **只能确认不能预测** | MACD 零轴上金叉质量远高于零轴下；RSI 50-70 强势区未超买 —— **放在最后做否决项，而非触发项** |

### 3.3 分批建仓 [接口] `concept.batch_plan`

| 阶段 | 动作 | 比例 | 说明 |
|---|---|---|---|
| 突破信号出现 | 建底仓 | 20%-30% | 首次突破不追高，只打底仓 |
| 回踩关键位不破 | 首次加仓 | 30%-40% | 缩量回踩突破位 / MA10 获支撑，是右侧最优加仓点 |
| 趋势延续确认 | 补足仓位 | 20%-30% | 沿 MA10/MA20 攀升，**总仓位不超过 70%** |

### 3.4 止损四规则 [接口] `concept.stop_rules`

1. **止损位置**：跌破入场信号失效位（跌破 MA20 且次日不收复 / 跌破突破位下方 3%）
2. **固定止损**：入场价下方 5%-8%，与均线止损**取较严者**
3. **时间止损**：入场后 3-5 个交易日未按预期上涨，主动离场释放资金
4. **绝不补仓摊低成本** —— 补仓摊低成本是左侧思维，与右侧「确认后才行动」的底层逻辑完全相悖

### 3.5 六条纪律 [接口] `rightside.discipline`

不猜底 / 不追高（**偏离 20 日线超 15% 一律不碰**）/ 不满仓（单笔风险 ≤2%）/ 不加仓摊平 / 不硬扛 / 不做无计划的交易。

## 4. 算法①：位置分级（pos1/2/3）

**判定量：距 MA20 偏离度 `dev20 = (price - MA20) / MA20 × 100%`** [接口] `rank[].dev20` + `level_key`

实测边界（2026-10-23 全量 166 只候选）：

| 档位 | 样本 | dev20 最小值 | dev20 最大值 | 推断阈值 |
|---|---|---|---|---|
| `pos3` 右侧安全位 | 35 只 | 1.02% | 4.87% | **≤5%** |
| `pos2` 中间位 | 100 只 | 5.00% | 14.70% | **5% ~ 15%** |
| `pos1` 追高位 | 31 只 | 15.07% | 72.80% | **>15%** |

阈值被后端显式声明：`thresholds.pos3_dev = 5.0`，以及 `market.signals` 文案「追高位（位置1）31 只已偏离 20 日线超 15%」[接口]。

位置三内部还有**三态**细分 [接口] `structure.pos3_state`：

| 三态 | 含义 |
|---|---|
| 真回踩 | 高低点同步抬高（HH/HL）且 MA20 未走坏 |
| 横盘整理 | 摆动结构尚未收敛（mixed），需等方向 |
| （其余） | 结构分歧（一升一降）、lh_ll（高点低点同步下移） |

## 5. 算法②：右侧六池（命中条件原文）

[接口] `rightside.pools[].scan` —— 这是全网最硬的选股条件，逐字抄录：

| 池 id | 池名 | 命中条件（原文） | 设计逻辑 |
|---|---|---|---|
| `breakout` | 突破确认池 | 突破 60 日新高 · 四线多头（**MA5>MA10>MA20>MA60**）· 当日**量比 ≥1.5 且收阳** | 突破关键位 + 均线多头 + 放量 → 价格结构确认 |
| `boll` | 动能突破池 | **倍量（量比≥2）**突破布林上轨且**突破幅度在 6% 以内** · MA5 向上 | 倍量突破布林上轨 → 动能与资金集中地确认 |
| `yearline` | 趋势确立池 | **近 5 个交易日内首次站上年线**（由空转多）· **MA120 向上** · MA5 > MA20 | 站上年线 + 120 日线向上 → 中长期由空转多 |
| `macd` | 动量确认池 | **MACD 零轴上方金叉** · 当日**量比≥1.2** · 非 ST | 零轴上金叉信号质量远高于零轴下 |
| `platform` | 形态突破池 | 近 20 日**振幅 <8%** 的窄幅平台 · 当日收盘突破平台高点 · **量比≥1.5** | 长期平台整理后放量突破 → 形态完成 |
| `pullback` | 回踩确认池 | **缩量（当日量 < 20 日均量×0.85）**回踩 MA10 不破 · MA5>MA10>MA20 · **近 20 日涨幅 >10%** | 突破后缩量回踩关键位不破 → 右侧最优买点 |

个股 `tags[]` 会标明命中的上位的通用特征：`四线多头排列 / MACD 零轴上 / MACD 金叉 / 量能放大` [接口]。

破位与走弱标的（12 只）**不进池也不进榜**，直接在源头剔除 [接口] `note`。

## 6. 算法③：右侧成熟度评分 + 综合分

### 6.1 成熟度 `score`（满分 90，五项子分）[接口] `rank[].sub`

|---|---|---|---|

### 6.2 综合分 `composite_score` = 三因子加权 [接口] `weights`

```
composite = 右侧成熟度 × 0.45 + 缠论体检 × 0.35 + 量价确认 × 0.20
```

| 否决原因 | 当日触发数 |
|---|---|
| 缠论分 < 70 | 137 |

### 8.2 两个分数，不可互相替代 [代码] L12397

- **`strategy_score`（策略适配分）**：只取右侧交易直接相关的五维 —— 位置安全度 / 趋势结构 / 动量确认 / 量价关系 / 缠论结构，**权重合计 0.60，归一后 0-100**。
- **`checkup_score`（12 维综合分）**：全科诊断，用来**找短板**（`weak[]`）。

### 8.3 结论三态与硬性否决

| verdict | 触发条件 |
|---|---|
| **可介入** | 无否决 且 strategy_score 达标 |
| **观察** | 无否决 但分数不足（如「策略适配 88.5 ≥ 80」这种 note 出现在可介入档） |
| **回避** | **命中任意一条硬性否决** |

实测否决串示例 [接口]：`["缠论反向：第三类卖点（三卖）", "斐波那契否决：K线形态反向（阴包阳（看跌吞没））"]` → verdict 直接判「回避」，**不看总分（60.8 分也回避）**。

### 8.4 流动性硬门槛 [接口]

`liq_min = 50,000,000`（20 日均额 5000 万）；不足直接 `liq_ok=false`，同时进右侧池的否决清单。

## 9. 算法⑥：缠论结构

### 9.1 结构口径 [代码] L5376 注释原文

> K 线包含关系 → 分型 → 笔 → 线段 → 走势中枢（延伸/扩展/新生）→ 背驰（MACD 面积 / 均线面积 / 区间套）→ 三类买卖点
> 笔按**新笔口径（两分型间隔 ≥4 根合并 K 线）**，线段为「笔破坏线段起点」的简化实现，中枢取「**至少三笔重叠区间**」并按走势类型判「盘整 / 上涨趋势 / 下跌趋势」。

### 9.2 评分与三档结论

| 档位 | 判据 |
|---|---|
| `resonance`（共振 · 最强档） | **评分 ≥70** 且买点成立 |
| `confirmed`（买卖点成立） | 结构成立但未达共振 |

## 19. 算法⑯：仓位计算器（纯前端）[代码] `pcCalc` L14205

```
风险额度   riskAmt = 总资金 × riskPct%          （默认 2%）
每股风险   rps     = 买入价 - 止损价             （≤0 直接报错）
理论股数   shares  = floor(riskAmt / rps / 100) × 100     ← A股 100 股整手向下取整
单票上限   maxAmt  = 总资金 × maxPct%           （默认 25%）
二次回砍   if (shares × price > maxAmt) shares = floor(maxAmt / price / 100) × 100
盈亏比     rr      = (目标价 - 买入价) / rps
```

判定链：价/止损 ≤0 → 报错；`rps ≤ 0` → 「这不叫止损，这叫没有止损」；`shares < 100` → 「连 1 手都买不起」；**`rr < 2` → 红字「低于 2:1 不值得占用仓位」**；分批建议 30% → 60% → 满仓。
