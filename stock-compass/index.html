量价分析 --

核心理念：量是因、价是果——上涨需要增量资金推动（放量确认），下跌可以无量阴跌。本模块基于经典量价方法论（威科夫「量在价先」一脉 + A 股公开复盘常识）独立实现：八种量价关系判定、放量突破 / 缩量回调 / 天量见顶 / 量价背离等关键信号、主力阶段推测（建仓 · 洗盘 · 拉升 · 派发）、按信号强弱给仓位建议，每项判定均附真实数值依据。
数据来源：新浪日 K（成交量不受复权口径影响）· 批量覆盖右侧六池与强势股标的；所有结论均不构成投资建议。

主升浪·腾飞点

方法论源自伍朝辉《腾飞点》（操盘大智慧系列丛书 · 伍朝辉精准系列，广东经济出版社 2012-12，ISBN 978-7-5454-1652-7）： 股价经过充分调整、完全化解前方套牢盘与获利盘压力之后，当天展开加速放量上涨的信号即为腾飞点， 是主升浪启动的标志性买点（区别于底部的「起涨点」与回调的「伏击圈」），书中分为起涨型与加速型两型。 本页将其公开的标准技术特征量化为七条条件自动判别，并内置量价闸门（与「量价分析」页签同源口径）： 量价 ⚠️ 警示（背离 / 天量滞涨 / 放量滞涨 / 假突破 / 巨量长上影）→ 按纪律不建仓； ✅ 确认（放量突破 / 缩量回调 / 低位堆量）→ 可进入买点流程；○ 中性 → 只观察。 榜单默认只展示「量价确认」一档，带警示的自动排除并扣分沉底。 操盘线（MA10）纪律：收盘打穿且 3 日不收复 → 行情终结； 8 / 13 个交易日内回抽构成第二头部 → 最后一卖。所有内容仅供研究参考，不构成投资建议。
